# Truck-Drone-Joint-Delivery-Route-Optimization-
基于自适应大邻域搜索算法(ALNS)的卡车-无人机联合配送路径优化系统，解决带时间窗的取送货问题(PDPTW)，实现卡车与无人机的协同配送优化。

## MATLAB 代码状态

已为仓库内全部 Python 源文件补充同名 MATLAB `.m` 对应文件，主要位于：

- `卡车无人机联合配送路径优化/ALNS/*.m`
- `卡车无人机联合配送路径优化/PDPTW-main/PDPTW/*.m`
- `卡车无人机联合配送路径优化/generate_data.m`
- `卡车无人机联合配送路径优化/local_search.m`

ALNS 可运行入口：

- `卡车无人机联合配送路径优化/MATLAB_ALNS/truck_uav_alns_main.m`
